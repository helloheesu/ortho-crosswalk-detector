# 코드·모델·데이터 권리

확인일: 2026-10-21. 프로젝트 코드에는 [AGPL-3.0-only](../LICENSE)를 적용한다. 해당 선언은 외부 라이브러리·가중치·영상·라벨의 조건을 대체하지 않는다.

## 프로그램

[Ultralytics](https://www.ultralytics.com/license)는 선택 YOLO 실행 의존성이며 AGPL-3.0 또는 상용 조건을 안내한다. AGPL은 비상업 전용 라이선스가 아니다. 해당 프로그램의 배포·변경·네트워크 제공 방식에 따라 고지, 대응 소스 제공, 동일 라이선스 등의 의무를 충족해야 한다. OSM 기여 목적이라는 이유만으로 면제되지 않는다. 결합 프로그램의 범위는 디렉터리나 저장소 개수로 결정하지 않는다.

다른 프로그램이 이 코어를 직접 import해 결합하는 경우 함께 검토해야 한다. 단순히 결과 데이터를 전달하는 것과 코드 결합은 구분한다. 수정 버전을 네트워크로 제공할 경우 해당 배포 버전의 대응 소스 제공 방법을 마련해야 한다. 현재 이 배포는 로컬 CLI다.

## 가중치와 입력

- Grounding DINO/Transformers는 별도 외부 구현이다. 모델 출처·revision·가중치 해시·선언된 라이선스를 실행 기록에 남긴다.
- SightLinks 공식 저장소의 MIT 표시와 YOLO 체크포인트의 AGPL-3.0 메타데이터는 구분한다. 공개 학습 자료의 license는 unknown으로 표시되어 있으며, 모델 배포자의 권리 보유를 독립 감사한 것은 아니다. 모델 설명 문서가 제공되는 경우 그 고정 출처와 해시도 확인한다.
- 영상·근거 crop·라벨·가중치는 소스 배포에 포함하지 않는다. 입력의 라이선스는 사용자별로 확인한다. 출처 표시만으로 사용·재배포 권한을 얻지는 않는다.
- 프로그램 출력이 모두 AGPL이 되는 것은 아니다. AGPL 2조는 출력 자체가 해당 프로그램에 기초한 저작물인지 구분한다. 영상 crop은 입력 영상의 권리가 별도로 남고, 학습 가중치와 추론 좌표도 구분한다.

## OSM과 소비 서비스

OSM 기여에는 [Contributor Terms](https://osmfoundation.org/wiki/Licence/Contributor_Terms)에 맞는 권한이 필요하며 후속 상업적 이용도 허용할 수 있어야 한다. OSM을 경유해 원본 조건을 없애는 구조로 설명하지 않는다. OSM 데이터 소비는 [ODbL](https://opendatacommons.org/licenses/odbl/1-0/)에 따라 별도로 판단한다. 소프트웨어와 데이터 라이선스는 서로 대체하지 않는다.

기존 검수 UI/Leaflet 파일은 이 저장소에 포함하지 않는다. 코드 라이선스를 선택한 것이 모든 입력·모델·서비스 구성의 적법성을 보증하는 것은 아니다.
