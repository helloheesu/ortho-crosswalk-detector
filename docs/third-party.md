# 외부 의존성과 공개 상태

프로젝트 자체 배포 라이선스는 아직 지정하지 않았다. 공개 전 코드의 배포 라이선스와 각 의존성의 이용 조건을 확인한다.

- Ultralytics는 선택 YOLO 실행 어댑터다. 공식 안내는 AGPL-3.0 또는 상용 라이선스다. 선택 의존성이나 저장소 분리만으로 결합 사용의 조건이 사라지지 않는다. MIT만 적용되는 전체 실행 환경이라고 안내하지 않는다. https://www.ultralytics.com/license
- Grounding DINO는 Transformers 기반 선택 모델 어댑터다. 모델 출처·리비전·라이선스를 실행 기록에 남긴다.
- 원본 영상과 모델 가중치는 포함하지 않는다. 사용자가 제공한 자료의 권리와 배포 가능 여부는 코드의 공개 여부와 별개다.
- 기존 검수 UI와 Leaflet 배포 파일은 이 저장소에 포함하지 않는다.
