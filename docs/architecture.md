# 탐지 도구 경계

입력 영상·메타데이터와 명시적으로 선택한 영역 → 좌표 점검·보정 → 겹침 타일 추론 → 후보 교환 데이터.

`catalog`는 입력과 미리보기, `geo`는 좌표, `models`는 모델 어댑터, `detection`은 실행, `exchange`는 후보 출력·검증, `records`는 DB 없는 기록 도우미, `cli`는 명령 진입점이다.

후보는 관측 단위이며 물리 시설 ID가 아니다. 좌표가 없으면 픽셀 후보로 유지한다. 모델 출력과 원본별 관측을 보존한다. 결과에는 사람 판정이나 서비스 업무 상태를 포함하지 않는다.

외부 검수 도구는 후보 묶음을 가져와 자체 판정·편집 기록을 소유한다. 탐지 서버나 검수 DB는 이 도구의 실행 조건이 아니다. 탐지용 GUI·독립 평가 데이터셋 API는 후속 범위이며 기존 통합 검수 프로토타입은 이 패키지에서 제외했다.
