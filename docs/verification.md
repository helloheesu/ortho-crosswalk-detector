# 검증 범위

독립 탐지 테스트는 합성 래스터와 테스트 대역을 사용한다. Flask·SQLite·검수 앱을 불러오지 않는 명령 실행, 입력 보존, 타일 계획, 후보 묶음 이동과 근거 검증, 실패·좌표 상태·출처 구분을 검사한다.

분리 후 테스트 및 wheel 검사 결과는 아래에 기록한다. 실제 모델 성능과 별개다.

2026-10-21 소스 분리 후: 전체 회귀 테스트 30개 통과(검수 저장소 테스트 포함), `pip check` 통과. 코어·검수 wheel 빌드 및 코어의 스키마 포함/검수 코드 제외 확인. 별도 디렉터리에 푼 코어 wheel을 검수 모듈 없이 import했다. 합성 무좌표 영상 테스트의 GDAL 경고 1개는 기존 동작이다.

## 실제 모델 개발 실험

[공개 집계 실험 이력](experiments/README.md)에 Grounding DINO 기준선, SightLinks nano/medium 비교, nano 점수 하한 조정의 결과와 한계를 보존한다. 가중치 추가 학습 및 독립 전수 성능 평가와 구분한다.

## 실제 기본값과 CLI 설정 · 2026-10-21

코어 24개 + 검수 앱 회귀 16개로 **40 passed, 1 warning**, pip check 통과. 새 설정 테스트는 모델·점수 생략 시 nano/0.01, CLI 우선순위와 실행 manifest의 적용값, 기존 명시적 작업 설정 유지, 모델을 로드하지 않는 plan, 사용자 가중치의 출처 필수·기본 모델 식별정보 제거, 잘못된 하한 거부, Python 실행부의 같은 기본값, 기본 가중치 해시 불일치 사전 거부를 검사한다. 테스트 모델 대역은 test_only다.

추가로 모델·점수 설정이 없는 작업 파일로 실제 영상을 실행해 nano/0.01·24타일과 완료 교환 데이터를 확인했다. 이 실행은 기본값 연결 검증이며 새 지역의 독립 발견률 평가가 아니다. 낮은 하한의 기존 결과와 원본·타일·박스·점수를 대조한 상세 결과는 상위 로컬 작업 자료에 보존한다.
