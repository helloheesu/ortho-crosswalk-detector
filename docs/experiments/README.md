# 실험 이력 · 2026-10-21

완료된 개발 실험을 공개 가능한 집계로 정리한 사후 기록이다. 추가 학습이나 모델 가중치 수정 이력이 아니라 **모델 선택과 추론 설정 개선 이력**이다. 원본 영상·개별 라벨·근거 이미지·가중치를 재배포하지 않는다.

## 같은 개발 자료에서 확인한 변화

| 실험 | 모델/하한 | 기존 확인 100개 대응 IoU ≥ 0.30 | IoU ≥ 0.50 | 후보 관측 |
| --- | --- | ---: | ---: | ---: |
| 기준선 | Grounding DINO / 0.20 | 7 | 7 | 185 |
| 전용 모델 비교 | SightLinks nano / 0.20 | 93 | 83 | 222 |
| 전용 모델 비교 | SightLinks medium / 0.20 | 93 | 82 | 201 |
| nano 하한 비교 | 0.10 | 96 | 86 | 249 |
| nano 하한 비교 | 0.05 | 96 | 86 | 263 |
| nano 하한 비교 | 0.02 | 97 | 86 | 308 |
| 현재 예제 | nano / 0.01 | 97 | 87 | 346 |

**97/100은 지역 전체 발견률 97%가 아니다.** 기존 GPT 후보에 사람이 판정한 기록은 전수 정답이 아니다. 세 개발 구역·62타일을 반복 사용했고 후보 관측에는 타일 간 중복이 있다. 모델 점수 하한과 평가 IoU를 구분한다. 새 후보 전체의 정밀도는 측정하지 않았다.

## 모델과 설정 선택

모델 교체로 기존 기록 대응이 증가했고, nano의 하한을 낮추면 추가 4개 기록과 대응하는 대신 관측이 222개에서 346개로 늘었다. 0.02와 0.01의 IoU 0.30 대응 수는 같았다. 알려진 목록 바깥의 후보를 성급히 버리지 않는 방침으로 현재 예제에는 0.01을 명시한다. 일반 엔진의 생략 시 기본값 0.15를 바꾸지 않았다.

동일 CPU 4스레드·768px 12타일·하한 0.01에서 한 타일 워밍업 후 세 번 측정한 순수 추론 중앙값은 nano 0.527초, medium 2.301초였다. 로딩·영상 읽기·결과 저장은 제외했으며 다른 하드웨어/전체 처리 시간으로 일반화하지 않는다. nano 가중치는 약 5.8MB, medium은 약 42.4MB다.

## 출처·재현 범위

영상은 [NGII 정사영상 공식 카탈로그](https://www.data.go.kr/data/15059919/fileData.do)에서 안내하는 국토정보플랫폼의 2025년·25cm 두 도엽이다. 2026-10-21 공식 카탈로그의 무료·이용허락범위 제한 없음 표시를 확인했다. 원본 식별·해시와 평가 정의는 [평가 맥락](evaluation-context.json)에 있다. 원본 권리를 코드의 AGPL로 바꿔 부여하지 않는다.

모델 고정 출처와 가중치 해시·선언 차이는 [모델 문서](../models.md), 코드/데이터 경계는 [외부 의존성](../third-party.md)에 설명한다. 초기 Grounding DINO 실행은 models.py의 정확한 당시 소스 복구에 공백이 있어 해당 기록에 명시했다. 이후 독립 CLI 반복 결과와 사후 소스 보존을 첫 실행과 동일한 것으로 꾸미지 않았다.

- [기준선 기록](01-grounding-baseline.json)
- [SightLinks 비교 기록](02-sightlinks-comparison.json)
- [nano 하한·속도 기록](03-nano-threshold-sweep.json)

JSON에는 집계·모델·설정·실행 코드 해시와 내부 보존 산출물의 해시를 담았다. 해시는 결과 증거의 연결 수단이며 이 공개 저장소만으로 동일 수치를 완전히 재현할 수 있다는 뜻은 아니다. 원본/평가 라벨을 제공하지 않으므로 독립 재현에는 별도 확보와 권한 확인이 필요하다. 공개 명령·예제로 다른 입력에서 실행할 수 있고, 독립 평가에서는 공간적으로 분리한 전수 라벨 구역을 사용해야 한다.

## 후속 구현: 실제 기본값과 실행 옵션

위 하한 실험 당시에는 예제의 0.01과 생략 기본값 0.15를 구분했다. 이후 사용자 요청으로 **실행부의 실제 기본값도 nano / 0.01**로 통일했다. 기존 실험 JSON·점수·하한은 변경하지 않는다. --model·--confidence·--weights 옵션과 적용값 기록, 명시적 기존 설정 유지에 대한 구현·검증은 [실행 설정](../configuration.md)과 [검증 기록](../verification.md)을 따른다.
