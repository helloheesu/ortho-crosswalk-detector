# 모델 준비

가중치는 저장소에 포함하지 않는다. 사용자 제공 로컬 파일/디렉터리와 출처·라이선스를 job.json에 명시한다. 횡단보도 전용 Ultralytics 모델의 클래스와 task를 검사한다. 일반 COCO 가중치를 횡단보도 전용 모델로 사용하지 않는다.

Grounding DINO는 추가 학습 없는 텍스트 조건 탐지의 선택 실험 경로다. safetensors와 설정·토크나이저를 로컬에 준비하고 고정 revision을 기록한다. 실행 중 자동 다운로드하지 않는다. 텍스트 프롬프트만으로 실제 횡단보도 탐지 성능을 보장하지 않는다.

[명령 설명](../docs/detection-cli.md)과 [외부 라이선스 경계](../docs/third-party.md)를 참고한다.
